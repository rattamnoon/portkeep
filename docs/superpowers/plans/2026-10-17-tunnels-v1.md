# Burrow v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A notarized macOS menu bar app that keeps named port forwards (SSH, AWS SSM, kubectl, GCP IAP, Cloudflare, custom) up, explains failures, and reconnects on its own.

**Architecture:** A SwiftPM library `TunnelKit` holds everything testable: the Codable model, argv building per method, port probing, failure classification, config importers, and a per-tunnel supervisor state machine driving child processes through an injected runner and clock. A thin SwiftUI app `Burrow` (MenuBarExtra + Settings) observes a `@MainActor @Observable TunnelStore` built on that library.

**Tech Stack:** Swift 6 (strict concurrency), SwiftUI/AppKit on macOS 14+, Swift Testing (`import Testing`), `swift-clocks` (tests only), Sparkle 2, XcodeGen.

**Spec:** [docs/spec.md](../../spec.md) · ADRs: [docs/adr/](../../adr/)

## Global Constraints

- macOS 14.0 minimum; universal binary; Swift 6 language mode, strict concurrency complete.
- Not sandboxed; hardened runtime on; `LSUIElement = YES`.
- No secrets written anywhere by the app (ADR-0005, ADR-0006).
- Child processes are launched from an argv, never a shell string, except the Custom method (`/bin/zsh -c`).
- SSH always gets `-N -o BatchMode=yes`; `ExitOnForwardFailure=yes` and `ServerAliveInterval=30` unless the tunnel overrides them.
- Readiness: TCP connect to `127.0.0.1:{L}`, poll 250 ms, timeout 20 s. Health: every 10 s, 2 misses → Retrying.
- Backoff sequence 1, 2, 4, 8, 16, 30, 60 s, then 60 s; reset after 60 s Connected.
- Stop = SIGTERM, SIGKILL after 3 s.
- Data file `~/Library/Application Support/Burrow/tunnels.json`, `schemaVersion` 1, atomic writes.
- UI colour: system accent + semantic colours only; status never colour-only; every row has a VoiceOver label.
- Repo work happens on a branch in a worktree after Task 1's initial commit; merge by squash PR.

## Review Focus

1. **App launched from Finder can't find `aws`/`kubectl`** (Homebrew PATH not inherited; user's shell is fish or bash) → tool lookup uses the login shell's PATH and still finds `/opt/homebrew/bin/aws`. Test in Task 3.
2. **App crashes or is force-quit with tunnels up** → next launch kills the orphaned `ssh`/`aws` children it recorded, so ports aren't left mysteriously "in use". Test in Task 6.
3. **Lid closed during Starting or Retrying** → on wake the tunnel restarts immediately, does not burn backoff attempts while offline, and never ends up with two child processes. Test in Task 6.
4. **Two tunnels configured with the same local port, both set to connect at login** → exactly one starts; the other is Blocked naming the first. Test in Task 7.
5. **`tunnels.json` hand-edited into invalid JSON** → the app does not overwrite it; it moves it to `.broken-…` and says so. Test in Task 2.
